## 根因与修复

1. **自然语言漏路由、误选技能。** 合同、新闻、创作者、标讯查询、投标编写缺少业务领域分类；“报告”又被同时用作多种文件格式触发词。增加业务分类，识别连字符名称，去掉错误的格式触发词。专用业务请求与平台海报目的地分别处理，保留同类候选的澄清流程。
2. **运行时忽略候选冲突。** 公共 Runtime 增加非调用路由处理，真正不确定时给出已启用候选，不让模型静默任选。原有 `/skills` 与技能详情命令保留。
3. **多轮确认丢失技能。** 将当前任务和技能写入真实会话 `mode_state`，支持“继续”“确认”等续接；成功交付后清理待交付状态，已禁用技能不能从旧状态恢复。大纲阶段的本轮限制不替代整体任务。
4. **文字声明被当作交付。** PDF、Word、PPT、Excel、HTML、CSV、图片等明确生成请求使用本轮文件发送证据；imagegen 另外要求实际生成脚本成功。检索类请求要求实际检索工具执行，加载说明和执行 `--help` 不算检索完成。
5. **证据随上下文压缩丢失。** 中间件直接记录工具执行结果，后续 Scroll 压缩不影响证据。没有证据的完成声明不输出到用户，也不以完成声明持久化；最多两次补执行后如实结束。
6. **文件存在却损坏。** 发送前验证非空、PDF 可解析、图片可识别、Office 文件 ZIP/XML 结构；失败保留源文件并返回发送错误，不发布成功下载链接。
7. **迁移技能依赖与工具名称不兼容。** 补齐 pandas、PyPDF2、defusedxml、youtube-transcript-api，固化文档生成库及 Poppler/LibreOffice 依赖。导入技能中的 WebSearch/WebFetch/AskUserQuestion 对应到当前运行时可用工具；缺少工具时说明阻碍，不虚构调用。

公共路由和证据处理复用同一套代码，不按智能体复制实现；文件验证单独承担格式检查职责。未提交、推送或创建 Git 分支。
