# 可复现技能包

此目录保存经过检查、可纳入 Git 的公开技能源码。它不包含本机或服务器的访问密钥、运行配置、技能安装状态、数据库记录或生成产物。

## imagegen

imagegen 使用当前配置的 OpenAI 兼容图片接口，默认模型为 gpt-image-2.5-sunburst、质量 xhigh；用户明确要求快速生成时使用 gpt-image-2.5-flare。高分辨率、编辑比例和旧模型兼容规则见包内 SKILL.md。

这是本阶段本地技能池新版本的源码归档，不会因检出代码自动替换智能体技能或发布旧服务器版本。导入时通过项目已有技能治理流程创建不可变来源版本，再对授权智能体执行安装或更新；不要直接改写历史快照或数据库来源绑定。

每个已有安装的私有配置需要保留。使用者应在私有技能配置或运行环境提供 OPENAI_API_KEY，并按实际部署配置 base URL；公开包不提供默认密钥。
