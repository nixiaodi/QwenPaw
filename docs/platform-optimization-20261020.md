# 平台登录、会话排查与技能授权调整

范围：本阶段涵盖登录退出、管理员会话查看、技能池可见范围与授权体验。经用户明确确认，本地业务数据库已备份并升级至 `0021_skill_public_admin_read`；用户随后确认将本阶段改动以详细中文说明提交、推送，并部署服务器。生产升级须先完成备份和迁移，再切换应用版本。

## 调整内容

1. 退出登录立即清理本地身份、会话缓存与用户工作区状态，通过前端路由返回登录页。服务端注销继续使用刷新锁串行执行，设置超时；显式退出后不再自动使用旧 Cookie 恢复登录。账号校验的延迟响应也必须通过会话代次校验。
2. 管理员在“会话 → 全部会话”选择任意智能体，查看全部用户会话、用户身份和消息详情。提供标题、用户及会话 ID 搜索、分页。详情使用大侧栏和聊天页共用的气泡、Markdown、代码块、推理与工具卡片；当前有效消息默认展示，原始记录通过顶部按钮切换查看。独立管理员接口和数据库行级策略同时校验权限，查看操作记录审计；未增加对他人会话的写权限。
3. 技能池增加“公用技能”开关。公用技能允许所有智能体的所有者及协作者载入，受限技能要求定向授权，停用技能一律禁止载入。授权检查同时覆盖目录、安装及更新，保留事务期间的权限锁。
4. 定向授权改为弹窗多选，一次请求在一个事务内完成全部目标授权，任一目标无效则整体回滚。新增“技能授权列表”分页展示技能、智能体、范围、授权状态、操作人与更新时间，支持搜索、状态过滤及撤销/恢复授权。
5. 核验现有普通用户发布流程：智能体所有者在“技能 → 申请发布”提交自己创建或导入的私有技能固定快照；管理员在技能池“发布申请”审核，批准后生成技能池发布版本。已发布技能可再设置为公用或定向授权。协作者和仅使用成员不具备代所有者提交权限。

## 数据兼容

- 新增迁移 `0021_skill_public_admin_read`，包含技能可见范围及管理员只读会话、消息策略；运行时数据库版本检查同步更新。
- 已有发布技能默认 `restricted`，保留原有授权，不会自动扩大可见范围。
- 关闭公用后恢复按定向授权判断；撤销定向授权不会限制仍设为公用的技能。
- 授权和公用设置不会自动安装技能，也不删除已经安装的副本。
- 部署时需先执行数据库迁移，再启动对应后端与前端。迁移已在独立临时测试数据库验证，随后经用户确认在本地业务库执行。生产部署同时打包迁移文件，停服备份后执行，避免新代码遇到数据库版本不一致而无法启动。

- 页面截图为测试数据；真实 PostgreSQL 权限测试使用独立临时容器，不访问生产接口。

## 本地验收入口

- 退出登录：登录后退出，登录页应立即显示；刷新后仍保持退出。
- 管理员：进入“会话 → 全部会话”，切换到其他用户创建的智能体并打开聊天式只读详情。需要查看已被编辑替换的内容时切换“原始记录”。
- 技能池：依次检查“已发布技能”的公用开关、授权弹窗多选和“技能授权列表”的搜索与撤销。
- 普通用户：在自己拥有的智能体技能页创建技能并申请发布；管理员审核后，将发布技能设为公用，另一新建智能体应可从技能池载入。

实现沿用现有权限服务、技能仓库、前端组件与请求封装；新增功能集中在授权判断和独立只读排查入口，避免扩大普通用户访问范围或引入额外依赖。

## 管理员会话详情展示调整

- 标签简化为“全部会话”。
- 详情采用大侧栏，复用聊天页历史转换、消息气泡和内容渲染器，默认隐藏已被编辑替换的旧消息。
- 聊天页和管理员详情共用后端历史投影，支持还原外置载荷、旧版快照及工具调用；缺失消息时间时使用数据库实际记录时间。
- 不提供发送、编辑、重试或审批动作；原始数据库记录保留在独立切换视图中。
- 本轮验证：后端相关 17 项、前端渲染与历史转换相关 43 项通过，正式构建与 Monaco 样式检查通过；浏览器验证聊天布局、Markdown 表格、代码块、工具卡片及原始记录切换。
- 本地真实历史抽样 3 条会话均成功还原，每条从 8 条原始记录得到 4 条当前有效消息。
- 测试数据界面预览：`build/platform-regression-20261020/admin-chat-view.png`。

## 头像与背景统一

- 只读详情沿用聊天页主题默认值、插件主题色和深色模式设置，助手头像使用同一插件配置或默认 `/qwenpaw.png`。
- 聊天区域背景采用同一主题填充色，消息气泡由共用组件生成，避免独立定义近似颜色造成偏差。
- 保留会话所属用户、智能体名称、消息时间和只读约束；浅色、深色模式均通过浏览器检查，头像资源成功加载。
