## 本地修复

`MemoryMiddleware.on_reasoning` 将本轮已完成的实际检索结果转换为标准工具事件，在模型输出前发送。使用原始检索的调用 ID、参数、内容及结果状态，不额外执行检索，不改变模型会话上下文。结果沿现有 SSE 和消息持久化链路进入会话历史。同一回复的后续推理不重复发送；没有命中、上一轮缓存和自动化请求不冒充当前检索结果。

统一中英文记忆提示要求模型先利用已有相关结果，实际使用记忆时简短说明来源；对于新政策等可能变化的信息，再核实当前来源，区分记录日期、生效日期和当前日期。这是所有采用该记忆中间件的智能体共用的逻辑，没有对公积金问题或某个智能体添加特殊路由。

既有历史消息不被重写。不同用户和不同智能体的私有记忆保持隔离。
