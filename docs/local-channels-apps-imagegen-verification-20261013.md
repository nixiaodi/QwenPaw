## 频道与 Slash

频道界面固定为“我的频道绑定”，只展示钉钉、飞书、微信、企业微信和 QQ。其他连接器仅隐藏，没有删除已存配置。

数据库唯一约束包含智能体、owner_user_id 和频道类型，同一个智能体可供不同用户分别配置自己的频道。绑定和凭据读写均从已认证用户派生所有者，监听器按绑定 ID 管理，会话归属于平台绑定所有者。

本次修复的是监听器仍共用智能体工作区的问题。缓存、媒体与微信凭据文件现在进入 user_workspaces/{user_id}/{agent_id}/channels/{binding_id}。复用现有工作区解析与预览授权，不放宽跨用户权限；每个绑定只构造目标连接器，避免混入默认 console。

验证覆盖双用户同一智能体、同一频道类型的配置与启停隔离，五个实际连接器的目录派生，以及本人文件预览 HTTP 200、其他用户 HTTP 403。多个用户复用同一个真实 Bot 仍可能受平台抢连接或重复投递规则影响，保留冲突提醒。

Slash 根因是无图标命令缺少 18px 图标槽和 8px 间距，标题因此提前 26px。现在所有候选统一保留图标槽，不改变执行逻辑或对特定命令做特殊处理。

## 应用

可安装应用 PawApp 是业务插件：应用中心下载包，经插件安装流程加载 manifest 和前后端入口，再注册页面、API、工具或技能。纯界面应用增加业务页面；实际注册聊天工具或技能时才可能增强智能体能力。聊天工具是否可用由智能体工具启用配置控制，工具默认禁用，安装状态本身不保证所有智能体都可调用。

应用可以提供项目看板、业务工作流、存储和长任务界面；技能主要提供模型可加载的操作说明和资源。第三方应用业务数据的用户隔离需按其实现另行验证。

共享应用则是审核发布的智能体版本，固定模型、技能、插件和 MCP 依赖。每个用户开始使用后获得独立会话和版本工作区。完整代码依据见 build/slash-apps-report-20261013.md。

## imagegen

调整前真实默认值为 gpt-image-2 / medium / auto。本机代理模型列表已包含 Sunburst 与 Flare。

- 默认 gpt-image-2.5-sunburst、质量 xhigh；仅明确要求快速出图时用 Flare。
- 快速请求只切模型，未要求降低质量时仍保持高质量和高分辨率。
- 16:9 默认 3840×2160，9:16 默认 2160×3840，方图默认像素上限内的 2880×2880。
- 编辑保持首张输入图的比例，用户明确指定模型、尺寸或质量时遵循其要求。
- 新图可显式使用 max；旧 Image 1 系列和 Image 2 使用各自兼容参数。
