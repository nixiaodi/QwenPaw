# 2026-10-13 本地应用安装可见性修复

Agent Kanban 0.1.1 已安装、启用并成功加载，但安装流程默认登记 `selected_users` 和空用户列表。应用中心与前端插件清单按真实用户授权过滤，所以连安装者也看不到，显示“我的应用 0”。这是安装流程与授权默认值衔接错误。

本地修复行为：

- 路径、市场 URL 安装与 ZIP 上传没有指定分享范围时，首次安装仅授权真实安装者。
- 区分“没有指定范围”和“明确指定空范围”；显式授权设置继续按请求执行。
- 没有指定范围的重装、升级保留现有授权，包括全员授权、指定用户及明确的空范围。
- 安装记录和授权在同一事务中处理，重装持有安装记录行锁，避免覆盖并发授权变更。
- 通过正常授权 API 恢复本机已安装 Kanban 对当前安装者的访问，保留修改前记录，不重新安装应用、不更改应用任务数据。

验证：

- 修复前，真实账号请求应用列表返回 200、total=0；插件运行状态 loaded=true、active，selected_users=0。
- 新增真实 PostgreSQL 和 ASGI 回归，首先复现了安装成功而列表仍为 0，再修复至通过。覆盖默认路径/市场安装、ZIP 上传以及三类授权范围的重装保留。
- 插件治理、安装仓储、应用信息与插件加载生命周期相关测试共 64 项通过。
- 本地正常重启后服务 ready，真实账号应用列表 total=1，包含 agent-kanban；前端清单、入口脚本及看板读取接口可访问。
- 其他用户访问该应用仍返回 404，匿名请求返回 401；诊断与修复使用的临时会话均独立撤销。

数据库回归运行在独立的 `qwenpaw_test_*` 测试数据库和每例临时 schema，不修改实际业务 schema。本次没有数据库结构迁移，也没有创建看板任务或调用付费模型。本次代码只在本地生效，服务器仍为上一阶段部署版本。
