# 首屏与会话历史性能优化阶段总结

## 阶段范围

本阶段在 `f5640c74`（登录退出、管理员全部会话、技能池公用与批量授权）基础上，解决刷新等待、长会话查看缓慢和大型工具输出带来的传输与渲染开销。上一阶段已有功能继续保留，不重复计作本次新增。

本次先完成本地实现与验收，再按用户明确授权执行中文提交、推送与应用发布。无新增数据库迁移，不手工修改线上用户、智能体、会话、技能或文件业务数据。

## 首屏加载与静态资源

- 移除全站页面 eager 导入及启动预加载，聊天路由改为按访问加载。
- Monaco 初始化、样式和 worker 仅进入代码编辑器时加载，保留离线 worker 映射和样式检查。
- Markdown、Prism 和附件卡片拆为延迟模块；普通文本和 stdout 直接显示，加载期间保留可读内容。
- 页面加载后注册完整模块导出，保留插件已有覆盖与引用；保持同步 antd/icons 宿主接口兼容。
- HTML、身份检查、插件及路由等待均提供加载状态。
- 归档此前 Nginx 静态资源 gzip、哈希缓存示例与诊断记录；本次发布不重复改写 Nginx 配置。

入口 JS 从 **13,676,536 B 降至 4,561,243 B**，减少约 **66.6%**；gzip 估算从约 3.85 MB 降至约 1.32 MB。此项是构建体积对比，不是公网端到端耗时保证。

## 会话请求与历史分页

- 列表查看使用轻量 summary 判断空会话，进入聊天页后只请求首批历史；浏览器验证为一次 summary 和一次 `page_size=5`。
- 共享会话权限轮询改为 summary，避免每 3 秒下载完整历史，并保留撤权感知。
- 恢复同步复用已取得的响应；更新运行时身份前核对当前会话与所有权，避免切换竞态。
- 普通及管理员历史首次只加载最近 5 个完整用户轮次，可继续加载更早消息。
- 数据库先查询用户边界，再读取选中轮次；使用排他 sequence 游标，保持顺序和工具调用/结果配对，排除已被编辑替换的展示消息。
- 旧格式使用稳定 ID，多输出记录可精确定位；处理分页去重、preload 缓存失效、切换取消和 SDK 滚动保持。
- 未传分页参数的完整历史接口保持兼容。

## 工具输出与原始记录按需读取

- 分页展示中超过 16 KiB 的工具输出替换为轻量占位与受权限保护的引用，点击后取得完整结果。
- 提供加载、失败重试、卸载取消和过期响应丢弃；摘要仅影响展示副本，不截断数据库原文或模型上下文。
- 管理员初始详情不再同时传输原始记录；切换后独立读取，每页最多 100 条，保留替换记录的审计语义。
- 新端点沿用普通、共享和管理员权限检查、RLS 与智能体归属限制。

321 条记录、含 2 MiB 工具输出的本地合成会话：完整历史 **2,197,205 B**，首批响应 **4,856 B**，减少约 **99.78%**。该合成样本与线上 18.55 MB 诊断样本不同，不混用比较。

## 验证与发布边界

- 前端：32 个测试文件、191 项回归通过；后端：202 项单元及独立 PostgreSQL 集成测试通过。
- 正式构建、TypeScript、Monaco CSS、变更范围 ESLint、Black 与 diff 检查通过。
- Chrome 验证正式构建的登录、技能池深链接刷新、普通/管理员分页、请求次数、完整工具输出及原始记录按需读取，无页面脚本错误。
- 浏览器业务数据使用本地模拟 API；SQL、权限和撤权语义由独立测试数据库验证。
- 发布包仅含已提交应用源码、既有迁移文件及正式构建，排除证书、私钥、运行配置、密码、数据库、日志和用户文件。
- 上线前备份，仅切换应用镜像，失败恢复原镜像；此次核对数据库版本，不执行升级或降级，不签发临时业务登录会话。

现有外置工具载荷缺少调用元信息，选中页的投影仍需读取相应文件以保留配对，本轮没有改写存储格式。正式构建仍有厂商重导出及大分包警告；产物静态分包图无环，主要页面执行已验证，尚未逐一运行所有外部插件。

本地步骤与证据见 [本地验收说明](local-performance-acceptance-20261020.md)，服务器实际发布结果见 [发布验收记录](performance-release-20261021.md)。
