## 一、已完成的代码优化

### 1. 长回答渲染

- 新增 `StreamingMarkdown`，复用现有 Markdown、代码块及产物链接处理。
- 正文达到 8,000 字符且仍在生成时，每 100ms 合并显示更新，减少重复 Markdown 渲染；短回答继续即时更新。
- 完成、失败、取消及只读历史立即显示完整内容，组件卸载清理计时器。
- 正文、生成状态和产物链接不变时复用渲染结果；响应标识参与组件身份，避免切换时沿用旧正文。
- 保留 SDK 全量事件接收、历史持久化、分页、队列和恢复逻辑，不截断回答。

### 2. 个人资料库管理

- 增加文件名/相对路径搜索、服务端分页及刷新；默认每页 20 条、最多 100 条。
- 增加重命名、移动、删除。移动保留文件 ID，可创建目标目录；页面不提供覆盖同名文件的选项。
- 删除操作要求页面确认；修改/删除携带列表中的 `updated_at`，识别过期操作并提示刷新。
- 提供重名、路径非法、资料已变化、无权访问及请求失败等反馈，阻止重复提交。
- 移动更新当前预览路径，删除关闭对应预览，删除末页最后一项后回到有效页。
- 补充同路径移动、元数据失败及文件删除失败时的处理，降低文件和元数据不一致的风险。
- 保留上传、预览、下载及从附件/产物导入资料的已有能力。

新增接口：

| 方法 | 普通入口 | 用途 |
| --- | --- | --- |
| GET | `/api/console/personal-library/documents/page` | 当前用户、当前 Agent 的资料搜索与分页 |
| PATCH | `/api/console/personal-library/documents/{document_id}` | 带版本检查的重命名/移动 |
| DELETE | `/api/console/personal-library/documents/{document_id}` | 带版本检查的删除 |

同时注册 `/api/agents/{agentId}/console/personal-library/...` 入口，复用同一套领域服务。

### 3. 沿用现有权限与隔离

- Agent 使用权限由 `get_agent_for_request` 及现有成员策略判断；文档所有者只取可信 actor，不接受客户端指定其他用户。
- 查询和修改都限定 `owner_user_id × agent_id`。管理员身份不额外获得其他用户私人资料的管理权限。
- 普通使用者管理自己的资料，不因此获得 Agent 配置编辑权。
- 检查路径与 Header 中的 Agent 一致性，拒绝成员撤销、错误代管上下文等绕过。
- 拒绝绝对路径、目录穿越、反斜杠、符号链接及内部 `.qwenpaw-index` 目录访问。
- 登录身份、Agent 或治理上下文变化时，清空列表、管理弹窗和预览；迟到请求不能更新新作用域的界面。

## 四、实现原则与边界

- KISS/YAGNI：采用局部增量修改，未引入新依赖、数据库迁移或新的授权模型。
- DRY：复用现有请求认证、路径解析、资料服务及 Markdown 组件。
- 职责分离：渲染节奏由显示组件处理，资料归属与生命周期继续由服务端管理，页面只组织交互。
- `updated_at` 校验用于阻止已过期操作，不是文件系统和数据库之间的跨进程原子事务；同时修改同一文件、进程突然退出后的恢复仍需专项建设。
- 资料列表搜索基于文件名/路径，不替代正文检索，也未增加 OCR、语义检索、重排表单或召回质量评测。
- 本次未解决旧前端插件与 Worker 协议的兼容问题，未完成 Hub 或真实多人执行隔离改造。

发布只包含已提交的应用源码和正式前端构建。凭据、TLS 证书、本地运行配置、业务数据和验证临时文件不进入 Git 提交或发布白名单。
