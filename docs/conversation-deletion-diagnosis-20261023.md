## 本地修改

聊天侧栏与抽屉共用的 SessionItem 删除菜单原先直接调用删除处理器。现在增加：

- 显示目标会话名称的二次确认，默认焦点置于取消按钮。
- 取消不调用删除；确认只调用原目标会话的处理器。
- 切换账号或智能体、原会话项卸载后，旧确认不能执行删除。
- 同一会话项不重复打开确认；只读或没有删除权限的项目禁用删除入口。

此变更只降低误触风险，没有将已删除数据自动恢复，也没有添加回收站、恢复 API 或补造历史审计。

本地验证：删除确认及会话所有权相关 3 个文件、28 项测试通过；TypeScript、变更范围 ESLint、正式构建和 Monaco CSS 检查通过。独立浏览器验收脚本尚未定位到预期会话项，未将这次浏览器尝试计为通过。
