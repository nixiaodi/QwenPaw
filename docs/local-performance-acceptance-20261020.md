# 本地性能优化验收说明（2026-10-20）

## 交付范围

本次修改仅位于本地工作区。未提交 Git、未推送、未部署，未连接或修改线上配置与数据。独立 PostgreSQL 测试使用 `qwenpaw-release-test-20261020-v2` / `qwenpaw_test_platform_20261020`，未修改业务数据库结构，无新增迁移。

## 已实现

- 首屏移除全站页面启动预加载和 eager glob；聊天页、Monaco 编辑器、Markdown/Prism、附件卡片按需导入。插件页面访问时注册完整导出，保留已有覆盖与模块引用；同步 antd/icons 宿主接口保持不变。
- HTML、身份、插件和路由等待阶段提供加载提示，避免启动期间白屏。
- 会话列表“查看”先读取轻量 summary；聊天页首次只读取最近 5 个完整用户轮次，避免前后两次下载完整历史。
- 共享会话权限轮询改为 summary，不再每 3 秒下载完整历史。后台恢复同步复用已取得的分页响应。
- 普通会话和管理员会话均可继续加载更早消息；边界位于用户输入处，保留同轮工具调用与结果；游标为 sequence 排他边界，排除被编辑替换的消息。
- 工具输出大于 16 KiB 时，分页响应只发送占位摘要和受权限保护的读取引用。点击“加载完整输出”后读取完整结果，支持加载状态、失败重试和切换后丢弃旧响应。原始输出、数据库消息和模型上下文保持完整。
- 管理员初始只读取聊天展示历史；切换“原始记录”后独立请求，每页最多 100 条。原始记录保留被替换的审计消息。
- 处理分页游标与短期 preload 缓存同步、稳定消息 ID 去重、SDK 滚动位置及恢复请求在切换会话后错误改写身份的竞态。

## 本地人工验收

入口：<http://127.0.0.1:18089/>。使用现有本地账号。

1. 直接打开并刷新 `/skill-pool?tab=published`，确认加载状态和页面均正常。
2. 从会话列表打开一条长会话，确认首先显示最近 5 轮；点击“加载更早消息”，向上滚动查看旧内容，切走再切回确认没有漏页或重复。
3. 管理员在“全部会话”切换智能体，查看长会话并加载更早消息。
4. 找到大型工具输出，确认首次只显示摘要，点击后才加载完整输出；失败时可以重试。
5. 切换“原始记录”，确认能独立加载和继续翻页；聊天查看仍为只读。
6. 如需使用代码编辑器，进入后确认编辑区、语法高亮、worker 与附件卡片正常。

## 边界

现有外置工具载荷缺少调用元信息，选中页面的后端投影仍需读取对应文件以保留工具配对；本轮减少的是查询范围、响应体积和浏览器初始化工作，未改写存储格式。普通聊天 SDK 还会对已下载历史分批显示，加载旧页后可继续向上滚动查看。

获得用户验收确认之后，再单独执行中文 Git 提交、推送和服务器部署。
